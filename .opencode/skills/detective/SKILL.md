# Детектив: разбор сцены по уликам

Ты не сочиняешь историю о фотографии. Ты прогоняешь сцену через
движок `ЭЛЕМЕНТАРНО` и показываешь **улики со ссылками на правила**.

«Шерлок» здесь — принцип, а не жанр: внимательно смотреть, сопоставлять
мелочи, идти от общего к частному. Сцены любые: кухня, кабинет, мастерская,
дача. «Кто это сделал» — частный случай, а не рамка.

## Движок

```
~/Projects/elementarno
```

Зависимостей нет (только стандартная библиотека). Для кроп-допроса нужен
Pillow: `cd ~/Projects/elementarno && nix develop --command ...`

Ключ MiniMax: `MINIMAX2_API_KEY` (или `MINIMAX_API_KEY`). Первый ключ может
быть исчерпан по лимиту — тогда работает второй.

## Команды

Один кадр, полный разбор с персоной:

```bash
cd ~/Projects/elementarno && python3 -m tools.elementarno.cli analyze photo.jpg --persona doyle
```

Только сцена-граф (посмотреть, что извлечено):

```bash
python3 -m tools.elementarno.cli perceive photo.jpg --out /tmp/scene.json --raw /tmp/raw.json
```

Только улики с цитатами и источниками:

```bash
python3 -m tools.elementarno.cli findings /tmp/scene.json
```

Два кадра: что изменилось

```bash
python3 -m tools.elementarno.cli diff before.json after.json --json
```

Загадка по серии кадров (в `puzzle.json` — список `participants` с `traits`):

```bash
python3 -m tools.elementarno.cli puzzle puzzle.json --persona doyle
```

## Лестница вывода

Ответ идёт по ступеням, каждая опирается на свои улики:

```
сцена → активность → присутствие → действие
```

Не перескакивай ступень. «Кто-то вошёл с грязными ботинками» нельзя сказать,
не сказав, что грязный след вообще найден.

## Правила, которые нельзя нарушать

1. **Не пересказывай вывод своими словами без цитат.** Каждое утверждение
   должно нести `[RULE-ID]`. Без цитат исчезает главное свойство.
2. **Не выдумывай улики.** Ноль улик — значит «улик недостаточно». Это
   корректный ответ, а не провал.
3. **Не поднимай уверенность.** Потолок задаёт правило (`confidence_ceiling`);
   черновиковое правило не обосновывает сильный вывод.
4. **Не переходи от улики к участнику напрямую.** Связь идёт через метки
   (`tags`) правила и `traits` участника. Нет совпадения меток — нет связи.
5. **Не выноси вину и не суди о характере.** Допустимы только: присутствие,
   действие, роль или привычка. «Виновен», «убийца», «преступник»,
   «по характеру видно» — валидатор отклоняет.
6. **Оговорки показывай.** У каждой улики есть `confounds` — именно они
   отличают вывод от фантазии.
7. **Интерпретация — отдельно.** Правило из слоя `semiotics` → пометить
   вывод спекулятивным и не выше 0.4.

## Персона

`--persona doyle` — повествование в стиле Конан Дойла, `forensic` —
исследовательский протокол, `plain` — нейтрально. Персона меняет тон, но не
содержание: утверждения, уверенности и цитаты те же.

## Если что-то сломалось

- `PerceptionError: не удалось получить корректный сцена-граф` — модель дважды
  нарушила схему; покажи `raw.json`, там видно, что она вернула.
- Пусто в `regions` при явных следах — модель не увидела отсутствие (известное
  слабое место). Предложи снять кадр с боковым светом, а не выдумывай улику.
- Нет `pillow` — кроп-допрос не выполняется. Запусти через `nix develop`.
