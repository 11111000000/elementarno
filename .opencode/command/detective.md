Разбери фотографии по протоколу ЭЛЕМЕНТАРНО.

Вход: $ARGUMENTS

Ориентиры:

- Если путь — файл изображения: разбери один кадр.
- Если путь — каталог или несколько файлов: разбери как серию, считай
  различия между соседними кадрами и строй версии по накопленному.
- Если путь — файл `puzzle.json`: это загадка с участниками и метками.

Обязательно пройди девять фаз из скилла `detective`: приём → описание →
след-проход → улики → проверка → утверждения → версии → вопрос → ответ →
журнал.

Пиши по-русски. Каждое утверждение — со ссылкой `[RULE-ID]`. Показывай
оговорки и проверку. Если улик недостаточно — так и напиши, и предложи
следующий кадр, который различил бы версии.
